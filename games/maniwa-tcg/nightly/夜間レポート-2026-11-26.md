## 2. 姫神演義 — 判断3 が36晩動かなかった本当の理由（SPEC 9.27）

### 2.1 ★ 前夜の見立ては外れていた

9.25.1 は残りを2つ挙げ、1つ目を「**`.field` に切り取られた名前を除外していない**」と見立てた。
**実測は違った。**

```
箱の中心の最前面: detail__art   ← カード詳細の幕が開いていた
```

駆動側の押下ループが `/もどる|やめる|とじる/` を除外しているので、
**札を押して開いた幕が閉じられないまま、その下の名前を測っていた。**

`.field` の内部スクロールによる切り取りは、**8通りの種で1件も該当しなかった。**
歯止めとしては残すが、**判断3 を止めていたのはこれではない。**
正しい歯止めは**覆い**である。

```js
const hit = document.elementFromPoint(b.left + b.width/2, b.top + b.height/2)
if (hit === null || !(hit === e || e.contains(hit))) 外す
```

### 2.2 ★★ 幕をどけた先に、もっと大きな穴があった

幕をどけても `ツァトゥグアEX` だけ「塗った画素0」が残った。計算後の値を見ると、
**消す前からすでに `color: rgba(0,0,0,0)` / `text-shadow: none`** だった。

**UR の名前はグラデーションを文字で切り抜いている**（`.is-gradient-text`）。
9.12 の測り方は「`color` と `text-shadow` を消した1枚との差分」なので、
**UR では2枚が完全に一致し、塗った画素が常に0になる。**

> **★ UR の名前は、9.12 を決めた 2026-10-10 から 2026-11-25 まで一度も測られていなかった。**
> 「0件」として数から外れていたので、**測れていないことが「違反なし」と見分けられなかった。**

消し方を両対応（`background-image: none` と `filter: none` も足す）にすると測れる。
芯もグラデーションなので、**UR だけは 9.12 手順4（計算後の `color`）が使えず、
画素から取る**（輪は `--card-edge` の輝度に近い群）。

## 3. 姫神戦記 — 待ち行列9 の15本目の軸（SPEC 9.36）

### 3.1 同じ穴はあった。しかも姫神演義より悪い

```css
.card__name            { background: var(--card-deep, #222); }   /* 不透明な下地 */
.is-gradient-text .card__name { background: var(--card-text); background-clip: text; }
```

`background` は一括指定なので **`background-color` が消える**。
さらに `background-clip: text` が効くので、**虹の名前には下地が1枚も残らない。**

| | 下地が不透明 |

| 非虹 | **3/3** |
| **虹** | **0/1** |

### 3.3 ★ 姫神演義の直しを持ってくると**悪くなる**

| 名前 | 1層（現状） | 6層 | 塗った画素 |
|---|---|---|---|
| カグツチEX | 芯と輪 **4.47** | **2.62**（悪化） | 943 → **168** |
| 焼き払う剣 | 芯と輪 3.46 | 6.57（改善） | 2045 → **600** |

**どちらも塗った画素が 1/4 以下に落ちている。縁が字そのものを食っている。**
原因は字の大きさで、**姫神演義は 13px、姫神戦記は 10px**。
姫神演義では画素が 1393 → 3420 と**増えた**のに、ここでは 943 → 168 と**減った**。

> **★ 同じ直しでも、字の大きさが違えば逆に働く。**
> 気付けたのは**「塗った画素の数」を比と一緒に出していたから**である。
> 比だけを見ていたら、焼き払う剣の 3.46 → 6.57 を見て「効いた」と報告していた。

### 3.4 今夜は直さなかった（理由）

- **6層は入れない**（10px では逆効果と実測）
- **下地の復活も入れない。** `background-clip: text` は同じ要素に下地を置けない。
  `::before` に置く案は負の `z-index` が虹の文字自体を覆うので成立せず、
  **グラデーションを子要素に移す**しかない。描画の構造を変えるので1晩の規模を超える
- **提案は1つ**: 虹のグラデーションを内側の `span` に移し、`.card__name` に
  `--card-deep` の下地を残す。虹も非虹と同じ土俵に乗り、無理な縁取りが要らなくなる
