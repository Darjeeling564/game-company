## 4. 姫神演義（B の夜）— 印が画面に居る時間

### 4.1 ★ 最初の計測は「運転の速さ」を測っていた

姫神戦記で 9.24（早送り中の印）を測ったときの手法をこちらにも当てた。
`requestAnimationFrame` ごとに一過性クラスの有無を見て、**DOM に居た時間**を数える。

**押す間隔を 80ms にした最初の計測では、`card__pop`（打点の数字）は
平均 255ms＝動きの 28% と出た。人の間合い（500ms）に直すと 534ms＝59% になった。**

**倍以上違う。** 一過性の印は次の描き直しで消えるので、**押すのが速いほど短く出る。**
最初の数字は**ゲームではなく運転の速さを測っていた**。以下はすべて 500ms の間合い。

### 4.2 測って分かったこと — 短いものは「殴った直後」に集まる

| クラス | 画面に居た平均 | CSS の長さ | 割合 |
|---|---|---|---|
| `burst`（着弾） | 151ms | 520ms | **29%** |
| `card--envenom`（毒） | 169ms | 520ms | **32%** |
| `banner--mine`（自分の番の帯） | 298ms | 700ms | **43%** |
| `card--lunge`（踏み込み） | 202ms | 420ms | **48%** |
| **`card__pop`（打点の数字）** | **534ms**（最短 117ms） | **900ms** | **59%** |
| `card--faint` / `points__pip--gain` | 269ms | 450ms | 60% |
| 残る10種 | — | — | 97〜209% |

攻撃は ダメージ → 気絶 → 登板 と描き直しが続くので、**その次の描き直しで消える。**

### 4.3 直したのは2つだけ。選び方は「情報が画面から消えるか」

| | 残るか |
|---|---|
| `card--lunge` / `banner--mine` | **残る**（踏み込みは自分の操作、帯は文字が残る） |
| `card--faint` / `points__pip--gain` | **残る**（盤から消えたこと / 丸の点灯） |
| `card--envenom` | **残る**（「毒」の札が付いたまま。9.4.7 と同じ理由） |
| **`card__pop`** | **消える。** 受けた打点の数字は、ここと**ログの4行**にしかない |
| **`burst`** | **消える。** 着弾そのもので他に手がかりが無い |

`card__pop` は `popRise 0.9s` で **25%（225ms）でようやく不透明になる**作りなので、
**最短 117ms では読める前に消えていた。**

### 4.4 直し方 — 消さずに持ち回り、**続きから再生する**

描き直しのたびに DOM を作り直すので、クラスを足し直すだけでは**最初から再生し直す**
（数字が何度も跳ね直す）。**出した時刻を控え、経過時間ぶんの負の `animation-delay`
を入れて続きから再生する。**

- 擬似要素には inline の `animation-delay` が効かないので、着弾は `--burst-age` を
  置き、`.burst` / `::before` / `::after` / `.burst--ur` の**4か所が同じ変数を読む**
  （既定値 `0s` なので、変数を置かなければ今までどおり）
- **きぜつの幽霊には重ねない**（9.4.3 の「1描画ぶん置き直す」を濁さないため）
- 控えは対戦をやり直したときに捨てる

### 4.5 直したあとの実測

| | 前 | 後 |
|---|---|---|
| `card__pop` | 534ms（59%・最短 117ms） | **1108ms（123%・最短 460ms）** |

本物の対戦で 394 標本を採り、**308 標本に負の遅れが入っていた**（最初の1描画は 0）。
不透明度は 0.00 から 1.00 まで連続して動いており、**跳ね直していない。**
写真は `shots-2026-11-14/` に1枚（打点の数字が浮いている対戦画面）。

### 4.6 直さずに残したもの

- `banner--mine` / `card--lunge` / `card--faint` / `points__pip--gain` / `card--envenom`
