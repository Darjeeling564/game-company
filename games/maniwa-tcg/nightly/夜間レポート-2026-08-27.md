## 7. 提案: 無属性の姫神に絶技を付けられない（実際に踏んだ）

### 何が起きたか

最初、**u011 を n003 タオテツ（中国・無属性）に付けた。** 中国は絶技0種、
無属性も絶技0種で、二重に穴を埋められる唯一の候補だった。
`rarity.ts` も `ultimate-check.ts` も通り、`card-value.ts` では
**寄与 +12.0pt（抜いた神威の雷より +4.1pt）** と良好だった。

しかし `npm run test` が落ちた。

```
FAIL games/maniwa-tcg/tests/pool-decks.test.ts > 回数を重ねればプール内のカードが全て選ばれる
AssertionError: expected [ 'u011 呑天食地' ] to deeply equal []
```

### 原因

`src/data/pool-decks.ts` の抽選が、絶技の候補を**デッキの属性の姫神からしか探さない**。

```ts
const mainPool = CREATURES.filter((c) => c.type === type)
const ultimatePool = ULTIMATES.filter((u) => mainPool.some((c) => c.id === u.requires))
```

無属性の姫神は `mainPool` ではなく `neutralPool`（共通枠）から取る。
そして `POOL_TYPES` に `colorless` は入っていない。したがって
**無属性を要求する絶技は、どのシードでも一度も選ばれない。**

`tests/pool-decks.test.ts` の「回数を重ねればプール内のカードが全て選ばれる」が
これを捕まえた。テストが機能した形で、`card-value.ts`（fixed デッキ）だけを見ていたら
気付けなかった。

### 今夜の対処

**カードの対象を f003 スルト（北欧・炎）に差し替えて通した。** 中国と無属性の穴は
埋められないままだが、テストを落としたまま提案するより、通る形で出すほうが良いと判断した。

### 提案

**SPEC 16.5.2 に「無属性の姫神には絶技を付けられない」を明記したい。**
現在この節は「中国・エジプト・インド・中東の4系統には該当する姫神がいない」とだけ書いており、
無属性の制約には触れていない。実際には n003 タオテツ が条件（最強ワザがコスト3）を
満たしているので、**書いていないと今夜のように踏む。**

書き足す案は2つある。

| 案 | 内容 | 影響 |
|---|---|---|
| **A（推奨）** | SPEC 16.5.2 に制約として明記し、無属性には付けない | 変更は文書のみ。実装は現状のまま |
| B | `pool-decks.ts` を直し、無属性の姫神も絶技の対象にする | 抽選の設計変更。専用キャラ枠と共通枠のどちらに数えるかを決め直す必要がある |

**推奨は A。** 無属性は全デッキに共通で2枚ずつ入る枠で、「そのデッキ固有の切り札」という
絶技の性格とそもそも噛み合わない。B で通せるようにすると、**どの属性のデッキでも
同じ絶技が撃てる**ことになり、絶技を属性ごとの個性にしている前提が崩れる。

どちらも SPEC の変更なので、承認をいただいてから書きます（CLAUDE.md 7章）。
