### 5-1. **2夜ぶんの指摘を撤回する — コントラスト違反109件は私の検査器の誤りだった**

2026-09-06 の点検で「`.gallery__rarity` のコントラスト違反 109件、R は比 1.35」と
報告した。**これは誤りである。CSS は正しく、違反は0件だった。**

原因は検査器にある。半透明の背景色を**合成せず、飛ばして親の色で判定していた**。

```js
// 誤（2026-09-06 と今夜の1回目）
const bgOf = el => { for (…) { const c = 背景色(e); if (c && c.a > 0.95) return c } … }
//                                              ↑ α=0.85 の下地を素通りして親へ行く
```

`.gallery__rarity` には `background: rgba(14, 30, 19, 0.85)` の暗い下地がある。
検査器はこれを飛ばし、その下のレアリティ枠色（R なら `rgb(200,210,216)`）で
判定していた。**実際に合成すると比は約 10.5 で、基準を大きく超えている。**

検査器を**上から順に alpha 合成する**方式に直したところ、全9画面で違反0件になった。
3-gallery.png の各カード右上を見ても、記号は下地の上で読める。

> **これで検査器の欠陥は2件目である。** 1件目は背景画像を除外していなかったこと
> （2026-09-04 の誤報）。**計測結果を疑う手順が要る。** 提案5 に書く。

#### (2) 対戦画面のカード名が読めない — **切れ2件 → 0件**

09-06 に「手札で36〜39pxしか無い」と挙げた件。**原因を特定した。**

```css
/* 変更前 */ .card .badge { float: right; }
```

`.card__name` は行数を切るために `display: -webkit-box` を使っている。
**これはブロック整形文脈を作るので、浮動要素を避けて箱の幅そのものが縮む。**
ベンチでは実測 29px しか残っていなかった。

バッジを**右上に重ねる**方式（`position: absolute`）に変え、名前は枠いっぱいを使い、
1行目がバッジと重なるぶんだけ `padding-right: 19px` で逃がす。
あわせてベンチだけ `-webkit-line-clamp: 3` にして縦に逃がした。

| 場所 | 変更前 | 変更後 |
|---|---|---|
| 手札 | 36〜39px | **54〜56px** |
| ベンチ | 29px | **49px** |
| 切られていた名前 | 2件（ラマッス・オオゲツヒメ） | **0件** |
