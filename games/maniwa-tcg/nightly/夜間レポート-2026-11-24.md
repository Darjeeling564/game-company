## 5. 姫神戦記（待ち行列9）— 掃いたら新しい違反が出た

### 5.1 6画面を3通りの種で掃いた

9.32（盤を固定）と 9.33（最悪の入力）で揃った仕掛けを使った。

| 画面 | 横スクロール | 切れ | **潰れ** | 44px未満 |
|---|---|---|---|---|
| ホーム | 0 | 0 | 0 | 0 |
| **カード一覧** | 0 | 0 | **3**（＝1画面につき1件） | **15**（＝5チップ × 3種。9.8.3 の既知） |
| デッキ一覧 / デッキ編集 / 対戦相手えらび / 対戦 | 0 | 0 | 0 | 0 |

潰れの中身は **`chips__label「レベル」幅34px / 字12px / 2行`**。

### 5.2 原因 — 見出しの幅が2px 足りない

```css
.chips__label { font-size: 12px; width: 34px; flex: 0 0 auto; }
```

見出しは **種類 / 属性 / レア / レベル / 効果** の5つで**最長は「レベル」の3文字**。
12px の字なら **36px** 要るのに **34px** しか無い。
**2px 足りないので「レベル」だけが2行になり、その行のチップが下にずれていた。**

`width` が固定なのは**チップの左端をそろえるため**で、それ自体は正しい。

### 5.3 直したもの

**`34px` を `36px` に書き換えるだけにしなかった。** それだと
**「12px」と「36px」という、片方を変えるともう片方がずれる組**が残る
（2026-09-26 の名前切れと同じ形）。**字数を1か所に書き、幅は `em` から導いた。**

```css
--chips-label-chars: 3;                       /* いちばん長い見出しの字数 */
width: calc(1em * var(--chips-label-chars));  /* 1em = 自分の font-size */
white-space: nowrap;                          /* 増えても折り返さない */
```

**直したあと**: 3通りの種すべてで**潰れ 0**。計算後の値も5つとも
**幅 36px / 高さ 17px（1行）/ `white-space: nowrap` / `--chips-label-chars: 3`** を確認した。
写真は `shots-2026-11-24/duel-絞り込みの見出し-直した後.png`。

**チップが 44px に届かない件（9.8.3・判断13）は取り決めなので触っていない。**
掃き出しの「44px未満 15」はそのぶんで、**意図どおり変わっていない。**
