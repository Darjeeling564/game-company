### 7-1.【直した①】手札が混んだときの名前切れ（09-18 の指摘・8夜目）

#### まず、測り方が間違っていた

1回目の計測は**切れ0件**と出た。対戦中の手札から複製して測ったためで、
**その手札に長い名前が1枚も入っていなかった**（実際の手札は3〜5枚）。

**プールで最も長い名前を流し込んで測り直した**ところ、こうなった。

| 手札 | カード | 名前枠 | 字 | **名前切れ** |
|---|---|---|---|---|
| 5枚 | 70×98 | 56px | 11px | **4件** |
| 6枚 | 68×95 | 54px | 11px | **5件** |
| 7枚 | 59×83 | 45px | 11px | **7件** |
| 8枚 | 53×74 | 39px | 9px | **8件** |
| 9枚 | 48×67 | 34px | 9px | **9件** |
| 10枚 | 44×61 | 30px | 9px | **10件** |

**9枚からではなく、5枚から切れていた。**

#### 原因はバッジが縮まないこと

| 手札 | カード | 名前枠 | **バッジ** | 逃げ | **1行目の取り分** |
|---|---|---|---|---|---|
| 5枚 | 70×98 | 56px | 16px | 19px | 37px |
| 8枚 | 53×74 | 39px | 16px | 19px | 20px |
| 10枚 | **44×61** | **30px** | **16px** | **19px** | **11px** |

カードは 84×118 から 44×61 まで縮むのに、**属性バッジだけが 16px のまま**だった。
`.card__name::before` の逃げは `19px` と直に書かれていたので、
**10枚のとき名前枠 30px のうち 19px を逃げが占め、1行目に文字が1つも置けない。**

SPEC 9.1.2 は「逃げるのは1行目だけ」を決めたが、**その1行目が丸ごと消えることまでは
見ていなかった**。9.1.2 の最後の一文が「起きるようなら行数か文字サイズの側で直すこと」
なので、それに従った。

#### 直した内容（SPEC 9.1.3 を追記してから実装）

1. **バッジの大きさと逃げ幅を1つの変数から導く。** 別々に書くと必ずずれる
   ```css
   .card { --badge: 16px; }
   .card__body > .badge { width: var(--badge); height: var(--badge); }
   .card__name::before { width: calc(var(--badge) + 3px); }
   ```
2. **手札が混んだらバッジも縮める**（8枚で13px / 10枚で11px）
3. **手札でも3行を許す。** 名前は絵の上に重ねてあるので（SPEC 9.2）、
   **行数を増やしてもレイアウトは1pxも動かない**。ベンチが 3.75em を許しているのと同じ理由
4. **バトル場は2行のまま。** 下にワザ行が続くので、伸びると重なる

#### 結果

| 手札 | 直す前 | 直したあと |
|---|---|---|
| 5枚 | 4件 | **0件** |
| 6枚 | 5件 | **0件** |
| 7枚 | 7件 | **0件** |
| 8枚 | 8件 | **0件** |
| 9枚 | 9件 | **4件** |
| 10枚 | 10件 | **6件** |
| 11枚 | 11件 | **3件** |
| 14枚 | 14件 | **3件** |

**実際に起きる範囲（5〜8枚）は完全に解消した。**
9枚以上に残るのは 9〜10文字の名前（「ニャルラトホテプEX」「ダイワスカーレット」
「アメン＝ラーの顕現」など）だけである。30px の枠に 9px の字で 10文字は
4行必要で、4行を許すと 61px のカードの 74% が名前で埋まる。**ここは残す。**

### 7-3.【直した③】演出の取り合いが2組残っていた（SPEC 9.4.16・新規）

#### まず「手札から場へ出る軌跡」は既にあった

題目の一覧では「まだ無い」とされていたが、**`cardPlace`（手札から盤面へ
奥に倒れ込みながら着地する）は実装済み**だった。

2026-09-20 に `.card--ultimate` が 2000試合で一度も画面に出ていなかった件があるので、
**全演出の出現数を数えた**（120試合・6312回の描き直し）。

| 演出 | 出た数 |
|---|---|
| `card--wounded`（静止） | 3574 |
| **`card--enter`（手札から場へ）** | **1709** |

| `card--swap-in` / `card--swap-out` | 80 / 80 |

**一度も出なかった演出は無い。**

#### 残っていた取り合いは2組

**総当たりではなく、実際に同時に乗った組を数えた**（9.4.13 の教訓）。

| 組 | 実測 | 消えていたもの |
|---|---|---|
| `card--lunge` + `card--faint` | **9件** | **`cardFaint`（きぜつ）** |
| `card--hit` + `card--swap-in` | **12件** | **`cardHit`（被弾）** |

**どちらも「自分に何が起きたか」が消える向き**で、09-24 に直した4組と同じ性質だった。

#### 直した内容

**踏み込み + きぜつ** — `lungeUp` は `transform` しか動かさず、`cardFaint` は
`transform`・`filter`・`opacity` を動かす。重なる `transform` を `cardFaint` が
全部上書きするので、**併走させても踏み込みは1フレームも残らない。**
そこで**きぜつだけを出す**。倒れる姿を見せないほうが損である。

**被弾 + 入れ替え** — `swap*` は `transform`+`opacity`、`cardHit` は `transform`+`filter`。
9.4.13 の `hit + lunge` と同じ形にし、**カンマの後ろに入れ替えを置いて、
被弾は `filter` の明滅を取り戻した**。揺れは戻らない。
`swap-out` との組は 120試合で **0件**だったが、同じ仕組みで片方だけ直っている状態は
あとで読み違えるので対で足した。

#### 画面に出ることを確かめた

止めて撮り、計算後のスタイルを読んだ。**`animation` が2つあるので `animation-delay` も
2つ書いている**（2026-09-25 の教訓）。

```
[lunge+faint]  animation: cardFaint
               transform: matrix3d(1,0,0,0,0,0.984808,-0.173648,...)
               filter: brightness(1.5) saturate(0.7) / opacity: 0.870423
[hit+swap-in]  animation: cardHit, swapInUp
               transform: matrix(1.03, 0, 0, 1.03, 0, -3)      ← 入れ替え
               filter: brightness(1.7) saturate(0.6)            ← 被弾が生きている
```

証拠: `shots-2026-09-26/fx-lunge-faint.png` / `fx-hit-swapin.png`

#### 手を入れなかった組

`hit + swap-out` / `hit + faint` / `hit + enter` / `enter + charged` は
総当たりではぶつかるが、**120試合で1件も起きなかった**ので触っていない。
`hit + ultimate`（40件）は 09-25 の `hitRing` で対処済み。

`prefers-reduced-motion: reduce` には新しい3クラスを追加した。
カード自体は表示されたまま残るので、動かさなくても情報は失われない。

## 10. 改善提案（根拠付き）

### 10.1 演出の題目の一覧が古い

夜間ジョブの規則にある「まだ無いのは**手札から場へ出るときの軌跡**」は、

### 10.2 `--badge` と同じ手を他にも当てられる

今夜の不具合は「バッジの大きさ」と「名前の逃げ幅」を**別々の場所に別々の数字で
書いていた**ことが原因だった。同じ形の組が他にもある。

| 組 | いまの書き方 |
|---|---|
| HP バーの高さ / その下の余白 | 別々の px |
| `.dock` の高さ / `.field` の `max-height` の引き算 | 別々の px |

**片方だけ変えるとずれる組は、変数1つから導く。** 今夜の `--badge` と同じ形にできる。
急ぎではないので提案に留める。
