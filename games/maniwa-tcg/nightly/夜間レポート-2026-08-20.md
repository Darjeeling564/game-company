## 4. 【要対応】新規カードを足すとデッキが黙って21枚になる

STEP6.5 で炎属性にキャラを1体足した時点で、**8デッキ中「ほのお」だけが21枚になり、
デッキ不正で全試合が開始できなくなった**（テスト8件が落ちた）。

原因は `decks.ts` のレシピが `main: FIRE_IDS` のように**属性の全カードを展開している**ため。
属性に9体目を足すと、そのまま9枚がデッキに入る。

```ts
// 修正前
...r.main,
// 修正後
...r.main.slice(0, 8),
```

**この1行だけ `decks.ts` に入れた。** バランスに関わる変更ではなく（既存の7属性は
ちょうど8体なので `slice(0,8)` は何も変えない）、新カードが黙ってデッキを壊すのを
止めるための構造修正である。既存カードの数値・配分には一切触れていない。

取り込みたくない場合はこの1行を戻せばよいが、**戻すと今後キャラを足すたびに同じ事故が起きる。**
