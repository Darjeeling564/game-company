## 3. デッキ地力の探索 — **今夜は探索した。7pt 縮む1枠が見つかった**

### 探索した理由

指示の条件「道標が新しく追加され、配り方の前提が変わった」に該当する。加えて、
**配置フェーズのコモン限定（SPEC 3.3.1）が入ってから配分を測り直していない**。
前夜に見つけた案はこのルールが入る前の前提で探したものなので、探し直しが要る。

### 測り方

- `decks.ts` は書き換えず、sim の `--swap` で実行時に差し替える
- 目的関数は**複数シードの平均レンジ**（ミラーを除いた各デッキの平均勝率の最大−最小）
- スクリーニング 2シード×3万戦 → 4シード×3万戦で検証
- さらに**探索に使っていない3シード**（123456 / 20260829 / 31337）で再現を確認
- **同じ種別としか入れ替えない。** SPEC 3.1.1 の内訳（神具3 / 道標3）を崩さないため

### 結果: 1枠だけで 7.16pt 縮む

### 提案2: 残り 16.7pt は1枠ずつでは埋まらない

山登りが1手で止まり、前夜の案とも足し合わない。**探索の手法を変える必要がある。**
指示にある「焼きなまし・3枚以上の同時入れ替え」を試す段階に来ている。

ただし1候補あたり2シード×3万戦で約10秒、2デッキ×6枠×22候補で1ラウンド約50分かかる。
同時入れ替えにすると候補数が二乗で増えるので、**時間の上限を決めてから着手したい**。

いまの偏りは次のとおり（今夜の1枠を入れた後）。

| デッキ | 平均勝率 |
|---|---|
| ほのお | 59.7% |
| みず | 57.3% |
| もり | 51.8% |
| やみ | 51.5% |
| かぜ | 48.2% |
| いかずち | 45.2% |
| ひかり | 43.7% |
| つち | 42.8% |

**ほのお・みずの2デッキが抜けている**構図。前夜まで「つちが弱い」と見ていたが、
つちを直した後は**上2つを下げるほうが効く**可能性が高い。

### 提案3: SPEC 17.6 のレンジを実測に置き換えたい（3夜連続の指摘）

SPEC 17.6 は「現在のレンジは 14.1pt」のまま止まっている。実測は 23.87pt。
SPEC 3.3.1 が「バランスの基準値はすべて測り直しになる」と宣言しているのに、
17.6 が更新されていない。**12章の指標にレンジを足す約束**（17.6 の末尾）も未実施。

基準値をいくつにするかは判断事項。実測ベースなら「**15pt 未満**」あたりが
現実的だと思うが、提案1を入れれば 16.7pt なので、まだ届かない。

### 提案4（判断待ちの持ち越し）: 先手勝率対策の案b が未承認

`startGame` の「後手は初期手札を1枚多く引く」は**まだ承認されていない**。
SPEC 3.3.1 には採用と書かれているが、明示的な承認の記録がない。
