**(1) 系統の偏り。** 日本と中東だけ2種で、他は3種だった。

```
日本 2 / エジプト 3 / 北欧 3 / インド 3 / 中東 2 / クトゥルフ 3 / ギリシア 3 / 中国 3
```

**日本と中東に1種ずつ足して、8系統すべて3種ずつで揃った。**

**(2) レアリティの偏り。** UR が `i021 グングニル` の1種しかなかった。

### 8-2. ⚠ 関門の定義に誤りがあった（規則の直しを提案する）

関門 8 と 10 は `origin/main` と比べる書き方になっていた。しかし**基点が作業ブランチのとき、
対話セッションの成果まで差分に入る。** 実際、今夜は `src/data/art/u008.webp` が拾われた。
これは対話セッションが昼間に取り込んだイラストで、**夜間ジョブは触っていない。**

関門8・10 が見たいのは「**夜間ジョブ自身が**禁止されたものを触っていないか」である。
正しい比較対象は `origin/main` ではなく**分岐点**だった。

今夜は両方で測り、次のとおり確認している。

```
分岐点（c50647e）からの差＝夜間ジョブが触ったもの
  7  0  games/maniwa-tcg/nightly/夜間レポート-2026-09-17.md
  （このあと support.ts への追加20行が加わる）

  data/core/tools の削除行 : 0
  art / package.json       : 空（触れていない）

origin/main からの差（テキスト）
  削除行 : 0（SPEC も 0）
```

**どちらの比較でも巻き戻しは無い**ので、関門の趣旨は満たしていると判断した。
**基準は緩めていない。** 誤りのある比較対象を、両方測ることで補っている。

**規則の直しを提案する。** 関門8・9・10 は `git merge-base` からの差で測るべきである。
あわせて、バイナリファイルは `--numstat` が `-` を返すので、
**削除行の判定はテキストファイルに限る**と書き添えたほうがよい。
