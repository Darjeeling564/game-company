## 5. 姫神戦記 — 待ち行列9（攻撃力の書き換わり）

### 5-1. 測って分かったこと

盤の姫神には `攻2100 / 守1700` が出ている。`effectiveAtk` は
`カードの値 + atkDelta` を返すので、**魔法で上下すると数字だけが黙って書き換わる。**

200試合・12959手で、`effectiveAtk` が前の手から変わった回数を数えた。

| | 回数 |
|---|---|
| 上がった | 168 |
| 下がった | 189 |
| **合計** | **357（1試合あたり 1.78 回）** |

**`atkDelta` はターンの終わりに 0 に戻る**ので、上がった数字は**次のターンの頭でまた戻る**。
プレイヤーから見ると、**同じ姫神の攻撃力が理由なく2回変わる。**
履歴には `攻撃力 -600` の行が出る（SPEC 9.14 で表に足した）が、
**盤の数字が変わった瞬間とも、どの姫神かとも結び付かない。**

### 5-2. 直し

9.4.23 と同じ形。**前回の値を持ち回り、変わった描き直し1回だけ**クラスを足す。

**動かすのはカードではなく `.card__foot` の最初の `.card__stat`（攻撃力の字）だけ。**
カード本体には `card--striking` / `card--struck`（`box-shadow`）と
`card--strike-up` / `-down`・`card--flip-*`（`transform`）が既に乗っている。
**子孫の字なら取り合い（9.4.13）は起きない。**

**両側に出す。** 相手の攻撃力が上がったことは、殴るかどうかの判断に直に効く（9.11 と同じ理由）。

### 5-3. ★ `transform` で動かす版を捨てた

`.card__foot` は **`overflow: hidden` で閉じてある**（攻守とレベルが枠を押し広げないため）。
9px の字を 1.25 倍にして 3px ずらす版を先に書いたが、**はみ出したぶんが切れる。**
場所を取らない `text-shadow` と `color` / `opacity` だけで出す形に書き直した。

動きを減らす設定も同じ理由で **`outline` は使えない**（要素の外に描かれるので切られる）。
`box-shadow` の `inset` で内側に引く。

## 6. ★ 今夜の計測の誤り1件

**攻撃力の印がどちらの側に出たかを `.field:nth-of-type(2)` で数えた。**
`renderDuel` は `far`（相手）→ `.board__line` → `near`（自分）の順に足すので、
自分の `.field` は **div としては3番目**にあたり、この選び方では当たらない。
結果は **「自分側 0 / 相手側 87」** と出た。
順番で取り直す（`[...querySelectorAll('.field')][1]`）と **73 / 14** だった。

> **3晩続けて同じ種類の誤りである。**
> 11-02 はクラス名に `--` を要求して `card__pop` を見落とし、
> 11-04 は `[a-z_]+` で `attachEnergy` を見落とし、
> **今夜は `:nth-of-type` が兄弟の型で数えることを忘れた。**
> どれも「**名前や位置の形を狭く決めつけて、0件という嘘を作る**」形である。
> **幸い今夜は「0件」が仕様（片側だけ）と食い違ったので気付けた。**
> 気付けたのは偶然で、**仕様が「片側だけ」だったら気付けなかった。**
