## 5. 姫神戦記 — 待ち行列9（手札に引いた札）

### 5-1. なぜここか

手札に1枚増えたことに手がかりが無く、**引けたのかどうかが画面から分からない**。
手札の枚数は画面に出ていないので、見落とすと取り返す手がかりが残らない。

### 5-2. 実装

引いた札は末尾に積まれる（`reduce.ts` の `hand: [...side.hand, top]`）ので、
`view.ts` に手札の枚数の控えを1つ持たせ、増えていたら末尾に一度きりのクラスを足す。
この画面は毎回 DOM を作り直すので `transition` は出ない（9.4.1）。`animation` で出す。

実測（本物の引いた札・390×844・dsf2）: `cardDrawn 0.26s ease-out`。
証拠は `shots-2026-10-25/fx-duel-drawn.png`。

### 5-3. ★ 動かさない設定で、止める指定が効いていなかった

`.card--drawn:not(.card--selected) { animation: none }` と書いたところ、
**引いた札がそのまま選ばれている描き直しで動きが止まらなかった**（実測。
`anim` が `cardDrawn` のまま残っていた）。引いてすぐ選ぶのは普通の操作なので、
これは珍しい場合ではない。

止めるほうは `:not()` 無しで書き、縁のほうにだけ `:not()` を付けて分けた。
直したあとの実測:

```
通常  : 引いた → cardDrawn ; 引いた＋選択中 → cardDrawn
reduce: 引いた → none ＋ outline 2px/offset 3px ; 引いた＋選択中 → none ＋ outline 3px/offset 1px
```

**両方とも止まり、選ばれている札の縁も奪っていない。**

### 5-4. ここは 9.4.4 / 9.5.4 / 9.6.3 と違って代わりを置いた

回転・ライフ・墓地は、動きを消しても数字か位置が残るので代わりを置かなかった。
**手札の枚数は画面に出ていない**ので、動きを消すと手がかりが完全に無くなる。
だから縁を置いた。姫神演義が 9.4.18 で同じ結論を出している。
