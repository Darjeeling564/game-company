`inDeck > 0`、つまり**基準デッキに入っているカードだけ**を数えている。基準デッキに

## 6. 【重要】絶技の設計基準に穴があった

### 何が起きたか

今夜の絶技の1枚目を **`s002 セイオウボ`**（森 / 中国）に付けた。指示どおり
「対応姫神の最強ワザ +10〜+20」を満たし（+17）、`rarity.ts` の検算も通った。

**それでも使用率 1.3% の死に札になった**（他の絶技は 22〜36%）。

### 原因

基準が**コストを見ていない**。

| | 絶技 | 対応姫神の最強ワザ | 効率比 |
|---|---|---|---|
| u001〜u008（既存） | コスト3 | **コスト3** | 1.10〜1.25 |
| 失敗した設計 | コスト3・評価77 | **コスト2**・評価60 | **0.86** |

セイオウボの最強ワザ「ふろうのみ」はコスト2で評価60、効率30。そこにコスト3で
評価77（効率25.7）の絶技を足すと、**基準は満たすのに1エネルギーあたりでは弱い**。
しかも絶技は撃つとターンが終わる。AI が撃たないのが正しい判断になっていた。

**2026-08-19 に u003 黄の印 が死に札になったのも同じ原因**である。当時は威力を
上げて対処したが、規則そのものは直っていなかった。

### なぜ既存の8種は無事だったか

**EX 姫神9体は全員、最強ワザがコスト3**だから。非EX 66体のうちコスト3は6体しかない。

```
EX 姫神:  最強ワザ コスト3 → 9体 / コスト2以下 → 0体
非EX姫神: 最強ワザ コスト3 → 6体 / コスト2以下 → 60体
```

「絶技は EX に付ける」という慣習は、飾りではなく**機能上の必然**だった。
型の上では `requires` にどの姫神でも指定できる（SPEC 16.5 にも EX 限定の記述は無い）
ので、知らずに非EXへ付けると壊れる。

### やり直した結果

系統の穴（中国・エジプト・インド・中東は絶技ゼロ）を埋めたかったが、
**この4系統には最強ワザがコスト3の姫神が1体もいない**（無属性の n003 タオテツ のみ。
ただし無は全8デッキに入っているため、絶技を付けるとどのデッキでも撃ててしまい
「1デッキ＝1絶技」の設計が崩れるので除外した）。

そこで系統の穴埋めは諦め、**機能する設計**を優先して対象を差し替えた。

### 提案

**SPEC 16.5 と夜間ジョブの指示の基準を、コスト込みに直したい。**

```
現行: 対応姫神の最強ワザより評価値で +10〜+20 上に置く
改定: 対応姫神の最強ワザと「1エネルギーあたりの評価値」で比べ、1.10〜1.25 倍に置く
      （＝最強ワザがコスト3でないと事実上成立しない。実質「EXに付ける」と同義）
```

既存10種はすべてこの範囲に収まっており、規則を変えてもカードの修正は要らない。
CLAUDE.md 7章に従い SPEC を先に直したいので、**承認をもらってから実装する**。

## 9. 改善提案

**いずれも人間の承認が要る。** 優先度の高い順。

### 提案1: 絶技の設計基準をコスト込みに直す（SPEC 16.5）

6章のとおり。**今夜これで死に札を1枚作った**し、2026-08-19 の u003 も同じ原因だった。
規則を直さないと3度目が起きる。既存10種はすべて新基準を満たすので、
**SPEC の文言を変えるだけでカードの修正は不要**。

### 提案2: レアリティの健全性判定を pool 側で行う（SPEC 12章）

5.1 のとおり。fixed のレアリティ表は基準デッキ内の104種しか数えておらず、
新しいカードが永久に検査対象外になる。sim の表に「基準デッキ内のみ」と明記するか、
判定は pool を見る、と SPEC に書き足したい。

### 提案3: 支援カードの配分を差し替える（12.4pt → 5.9pt）

2026-08-21 からの持ち越し。探索は収束済みで、**適用の承認待ち**。

### 提案4: 絶技ゼロの系統をどう埋めるか決める

中国・エジプト・インド・中東には絶技が無いが、6章のとおり
**この4系統には絶技を機能させられる姫神が1体もいない**（最強ワザが全員コスト2）。
埋めるなら次のどちらかが要る。

- これらの系統に**最強ワザがコスト3の姫神を新規追加**してから、絶技を付ける
- 絶技のコストを2にする種類を作れるよう、SPEC 16.1 の「コスト3」前提を見直す

前者のほうが影響が小さい。次に姫神を足す夜（ローテーション上4夜後）に、
この4系統からコスト3の姫神を作るのが素直だと考える。
