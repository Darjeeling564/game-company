直前の A の夜（10-25）が神具だったので、順番で**道標**。

| UR | 8/8 | — |
| SR | 8/8 | — |
| R | **7/8** | **japan** |
| C | **5/8** | **norse / egypt / india** |

R は japan の1つだけ。C は3つ空いているので、**系統ごとの枚数が最少だった india**

### 4-2. ★ 採用は勧めない。理由を数字で書く

SPEC 17.6 の目的は**デッキ間の地力の差を縮めること**である。
ホールドアウト（12000戦）での基準デッキの地力はこうだった。

```
ほのお 48.5 / もり 50.5 / かぜ 50.7 / つち 51.4 /
いかずち 49.5 / みず 48.6 / ひかり 51.5 / やみ 49.2
レンジ 3.08pt（最強 ひかり / 最弱 ほのお）
```

**もり（50.5%）も つち（51.4%）も弱いほうではない。** ここに +4.1pt / +2.9pt を足すと
レンジは 3.08pt から **6pt 台に広がる**。縮める方向に効く みず・ひかり の差し替えは、
ホールドアウトでは +0.58pt / +0.25pt しか無い。**今夜の2枚で縮む案は見つからなかった。**

### 4-3. ★ 「ひかりが最弱」は、シードによって入れ替わる

学習3シードの平均では **ひかりが最弱（46.7%）** で、これは 10-19 から繰り返し書いてきた。
ところが**ホールドアウトでは ひかりが最強（51.5%）**で、最弱は ほのお（48.5%）だった。

| | 学習3シード平均（4000戦×3） | ホールドアウト（12000戦） |
|---|---|---|
| ひかり | **46.7%**（46.6 / 48.6 / 44.9） | **51.5%** |
| ほのお | 48.9%（47.4 / 48.4 / 50.9） | **48.5%** |

学習側は3シードとも低いので、ばらつきだけで説明するのは苦しい。
しかし 4000戦だと**1デッキあたり 440戦ほど**しか回らず、標準誤差は 2.4pt 近い。
**この規模では「どのデッキが最弱か」は確かなことが言えない。**

**判断5番（ひかりの `a023`→`a034`）の前提がここに掛かっている。**
採否を決める前に、**同じ物差しで何シードか取り直す**ことを勧める（判断7番の
