## 4. 姫神演義（B の夜）

### 4.1 新しい演出 —「あと1点」

**まず、どれだけ起きるのかを数えた**（`core` だけで 2000 戦・盤面 104620 回）。

| | 実測 |
|---|---|
| 「あと1点」の盤面 | **全盤面の 20.0%** |
| 「あと1点」が1度でも出た試合 | **85.0%** |
| 両者が同時に「あと1点」 | 21.1% |
| 「あと1点」でいたターン数の平均 | **4.3 ターン** |

**対戦のいちばん張り詰めた2割に、専用の手がかりが1つも無かった。**
丸は点灯したままなので、**「2つ点いている」と「あと1つで負ける」が同じ絵**である。

**出し方**: 点いた丸ではなく、**残っている空の丸**をゆっくり脈打たせる。

- 空の丸にしたのは、**`points__pip--gain`（9.4.8）と `animation` を取り合わない**ため。
  空の丸に `--gain` は付かないので、**取り合いが構造的に起こらない**（9.4.13）
- 「ここが埋まったら終わり」を直接指すので、読むのが短い

### 4.2 ★ 無限の動きは、描き直しで位相が戻る

9.17 で打点と着弾に入れたのと同じ問題が、**無限の動きにもある**。
本物の対戦で実測した。

| | 実測範囲 | CSS の振れ幅 | 到達率 |
|---|---|---|---|
| `energy__orb` の `scale`（`orbPulse` 1.5s） | 1.000〜1.114 | 1〜1.12 | **95%** |
| `card--attachable` の `outline-offset`（`attachPulse` 1.4s） | 2.00〜4.00 | 2〜5 | **67%** |

`orbPulse` は困っていない（自分の番は描き直しが来ないので走り切る）。
**`attachPulse` は3分の1を失っている。** どちらも死んではいないので**既存は触らない**。

**ただし新しく足すものは最初から位相を持ち回る。** 「あと1点」は平均 4.3 ターン続き、
その間ずっと相手の番の描き直し（450ms ごと）が挟まる。位相を戻すと
**脈が出かかって止まる絵**になる。負の `animation-delay` に経過時間の剰余を入れた。

### 4.3 動きを減らす設定

**止めるだけにしない。** 脈の代わりに、残った丸の縁を点灯の金（`#ffd678`）にして太くする。
**`points__pip--gain` の代わり（9.16.4）は `outline`、こちらは `border`** なので、
同時に出ても取り合わない。

### 4.4 直したあとの実測

| | 通常設定 | 動きを減らす設定 |
|---|---|---|
| 空の丸の `animation-name` | **`pipReach`** | `none` |
| 位相（inline の遅れ） | **`-368ms`**（描き直し後も続く） | — |
| 空の丸の `border` | 脈の途中の色 | **2px / `#ffd678`** |
| 点いた丸の `animation-name` | `none`（取り合い無し） | `none` |

写真は `shots-2026-11-16/` に1枚（金の丸2つ＋残り1つが光っている帯）。
