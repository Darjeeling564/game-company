## 5. 姫神戦記（待ち行列9）— 判断25 を解いたら、前夜の報告が誤りだと分かった

### 5.1 盤はゲームを触らずに固定できた

11-21 に「盤が毎回変わるので再現しない。ゲームに種を渡す口が要る」と書いて
**判断25 として提案に回した。その必要は無かった。**

```js
await page.addInitScript((s) => { Date.now = () => s; Math.random = () => 0 }, SEED)
```

`startDuel` の種は `(Date.now() ^ (Math.random() * 0xffffffff)) >>> 0` なので、
**両方を固定すれば盤が再現する。** 同じ種で手札が一字一句同じになり、
別の種では変わることを実測した。**`game` のコードは1行も変えていない。**

### 5.2 ★★ 訂正 — 11-21 に報告した「潰れ」は最初から無かった

再現する盤で測り直したところ、**9.31.5 で報告した
「`card__name`「シュブニグラス」が幅12px・4行に潰れる」は一度も再現しなかった。**

原因を追ったところ、**盤のランダムさではなく計測器のほうだった。**

- `getBoundingClientRect()` で幅を測っていた
- **守備表示の姫神は90度回っている。** 外接箱は幅と高さが入れ替わる
- `card__name` は CSS 上 **78px 幅**なのに、外接箱は **11px** を返していた

> **★ これは 2026-09-20 に記録済みの罠を踏み直したものである。**
> 「**`transform` が乗っている要素は `getBoundingClientRect()` で測らない。
> `offsetWidth` / `offsetHeight` を使う**」と、夜間ジョブの手順書にも SPEC にも書いてある。
> **書いてあるのに踏んだ。**

`offsetWidth` で測り直した結果。

| 文字の倍率 | 盤 | 潰れ | 切れ |
|---|---|---|---|
| 1倍 | 8通り | **0** | **0** |
| 1.3倍 | 8通り | **0** | **0** |
| 1.5倍 | 8通り | **0** | **0** |

**どの倍率でも、どの盤でも潰れも切れも無い。**
9.31.2 の**ターン欄が 1.5倍で 52×132 に潰れる**ことは変わらない
（`.turn` には `transform` が乗っていないので、あちらの測定は影響を受けない）。

### 5.3 訂正の仕方について

STEP6.6 の条件は満たすが、**SPEC 9.31.5 の本文を書き換えると削除行が出て関門d3 が落ちる。**
そこで**本文は消さず、9.32 を追記して訂正の履歴を引用ブロックで残した。**
STEP6.6 の「枚数のような毎回古くなる数字は訂正より提案を優先してよい」と同じ考え方で、
**追記で上書きできるものは追記にする**ほうが、マージを止めずに事実を残せる。
