### 7-1.【直した①】絶技を撃ちながら倒れるときに、倒れる姿が出ていなかった

**測り方を変えた。** 09-26 までは総当たりで「ぶつかりうる組」を出してから実測で
絞っていたが、今回は**実際に同時に乗った組から始めた**。120試合の走査で
同時に乗った組は **20組**、そのうち演出が消えるのは **3組**。

| 組 | 実測 | 残る | 消える | 判断 |
|---|---|---|---|---|
| `card--hit` + `card--ultimate` | 34件 | `cardUltimate` + `hitRing` | `cardHit` | **意図どおり**（9.4.15） |
| `card--lunge` + `card--faint` | 7件 | `cardFaint` | `lungeUp` | **意図どおり**（9.4.16） |
| **`card--ultimate` + `card--faint`** | **1件** | `cardUltimate` | **`cardFaint`** | **向きが逆。直した** |

9.4.16 で決めた向きは「**残すのは『自分に何が起きたか』のほう**」である。
絶技は自分がしたこと、きぜつは自分に起きたことなので、**きぜつが残らねばならない**。

両者とも `transform` と `filter` を動かすので**カンマでは救えない**。片方だけを出す。

```css
.card--ultimate.card--faint { animation: cardFaint 0.45s ease-in both; }
```

**一回転が消えても、絶技の証しは残る。** 溜めの輪は `.card--ultimate::before` にあり、
擬似要素は別の `animation` なのでこの規則の影響を受けない。

**画面に出ることを確かめた**（`shots-2026-09-28/fx-ultimate-faint.png`）。
`cardFaint` の山（135ms）で止めた時点の計算後のスタイル:

```
animationName: cardFaint      duration: 0.45s
transform: matrix3d(...)      filter: brightness(1.5) saturate(0.7)   opacity: 0.870
::before  animationName: ultimateCharge   opacity: 0.967
```

**輪が 0.97 の濃さで並走している。** 撃った証しが出たあとで倒れる形になっている。

SPEC 9.4.17 を追記してから実装した。`prefers-reduced-motion` にも追加済み。

### 7-3. 計測の誤りを2つ踏んだ（どちらも報告前に気付いた）

**★ この2つは、報告してしまえば嘘になっていた。**

#### ① 「6枚から切れている」は私の計測が作った数字だった

最初の計測では 6枚で3件・7枚で6件の切れが出て、

切れが水増しされていた。当て直すと 6〜8枚は 0件である。

**09-26 の「中身だけを複製して測ると実際より良い数字が出る」の裏返し**で、
今回は**悪い数字**が出ていた。複製して測るときは、枚数で付くクラスを自分で当てる。

#### ② 演出の出現数の集計は盤面しか見ていない

09-24 以降で使っている集計は `.card--board` だけを走査している。
