## 7. 直したもの・作ったもの（STEP6.5-B）

### 7-1. 【8夜積み残し】2件とも、実測では違反していなかった

09-10 から「判断が要る」として残してきた2件を、今夜きちんと数字にした。

**(1) 盤面の 235px のはみ出し → 違反ではない**

```
8-battle  : 盤面の中身 817px / 枠 613px / はみ出し 204px / dock の上端 634px
8b-finish : 盤面の中身 817px / 枠 644px / はみ出し 173px / dock の上端 665px
```

SPEC 9.3.1 が求めているのは「**ボタンと手札が viewport 内に入っているか**」である。
**dock の上端は 634px / 665px で、844px の画面に収まっている。**
盤面の内側スクロールは 9.3.2 で設計として入れたものなので、
はみ出し 204px は**仕様どおり**であって違反ではない。

**「235px のはみ出し」という書き方が、判断を8夜止めていた。** 数字の名前が
悪かったのであって、直すものは無い。

**(2) 手札9枚以上の 44px 違反 → 起きていない**

9枚の手札を実際に捕まえて測った。

```
手札9枚のときのカード: 55×72 53×71 51×69 50×68 48×67 50×68 51×69 53×71 55×72
44px違反: 0件
```

**最小でも 48×67px** で、44px 四方を割らない。`.hand > .card` は
`width: 23% / max-width: 86px / flex: 0 1 auto` で縮むが、9枚では 48px で止まる。

**この2件は今夜で閉じる。** ただし (2) は**10枚以上を測っていない**ので、
そこは未確認として残す（9枚は実測、10枚以上は未観測）。

### 7-2. 【新しい手がかり】上に隠れている段（SPEC 9.3.3）

9.3.2 で盤面を内側スクロールにしたとき、**下に続きがあること**の手がかりは
入れたが（`.field__more`）、**上に隠れている段には何も無かった。**

実測のとおり盤面は 204px が枠の外にあり、少し下へ送ると**相手のベンチが
画面から消える**。消えたと分かる手がかりが無い。

SPEC 9.3.3 を先に追記してから実装した。

| 位置 | 印 |
|---|---|
| 下に続きがある | 従来どおり `.field__more` |
| **上に隠れている** | **`.field__less`**（新規） |

**形・色・持続時間は下の印とまったく同じにし、向きだけを返した。**
別物に見えると、同じ意味だと読み取れないため。矢印そのものは描かず、
隅を2辺だけ描く（9.3.2 と同じ理由。押せると思われる）。
`prefers-reduced-motion` の一覧にも足した。

**画面に出ることを確かめた。**

```
送る前 : 中身842 / 枠593 / 位置0   上の印 field__less（--on なし）
送った後: 位置120               上の印 field__less field__less--on
          不透明度 1 / sticky top=0px / 膜 linear-gradient(rgba(18,42,27,0.92)…)
          印の枠線 2px / 2px
```

スクリーンショット: [`shots-2026-09-18/fx-field-less.png`](shots-2026-09-18/fx-field-less.png)
（上端に膜と上向きの印、下端に従来の下向きの印。上下対称になっている）

### 7-3. 【今夜の違反】手札が混んだときの名前切れ — 3件 → 1件

手札9枚のときのカードは 48×67px まで縮み、**名前の枠が 34×28px** になる。
「カグツチEX」「双龍の采配」「フェンリル」が3行（41px）必要で切れていた。

**8枚以上のときだけ名前を一段小さくした**（11px → 9px）。

```css
.hand:has(> .card:nth-child(8)) .card__name {
  font-size: 9px;
}
```

7枚以下は従来どおり 11px のまま。**同じ9枚の手札で測り直して 3件 → 1件**になった。

#### 残る1件は判断が要るので提案に留める

```
[clip] .card__name 「星辰の羅針」 34/34 34/23
```

9px でも**3行必要**（34px）で、2行ぶん（23px）しか無い。原因は
**バッジの逃げ（`::before` の 19px）が1行目を潰していること**で、
34px の枠のうち 19px が逃げに使われると1行目に1文字しか入らない。

直すには次のどちらかを選ぶ必要がある。

1. **名前の箱を3行に広げる** — カードは 67px しかなく、絵と HP が押される
2. **混んでいるときは1行目をバッジの下に潜らせる** — 逃げをやめる。名前は読めるが重なる

**どちらも見た目の好みが分かれる**ので、今夜は手を付けない。
