## 4. ★ 姫神戦記 — 待ち行列9（画面の計測と直し）

### 4-1. 測って分かったこと：**この画面では `transition` が原理的に出ない**

`renderDuel` は毎回 `root.textContent = ''` から組み直す。
実機で印を付けて数えた（390×844 / dsf2）。

| | 描き直し前 | 描き直し後 |
|---|---|---|
| 印の付いた手札の札 | 4 | **0**（札そのものは4枚ある） |
| 印の付いた盤の札 | 1 | **0**（札そのものは1枚ある） |
| 印の付いた入れ物（`.board` / `.hand`） | 2 | **0** |

**新しい要素には「変化の前の値」が無いので、CSS の `transition` は発火しない。**

> **既にある `.hand__slot .card { transition: transform 0.12s ease-out }` は、
> この理由で一度も効いていなかった。** `.card--selected` の `translateY(-8px)` は
> 毎回いきなり出ている。**この行は消していない**（消すと「なぜ無いのか」が分からなくなる）。

### 4-2. ★ 危うく嘘を報告しかけた

reduce の監査（10-20 の手法）で `.card--defense` の `transform` が
**単位行列（＝回っていない）**と出た。CSS には `rotate(90deg) scale(0.7)` と書いてある。

**現物を測り直したら、違った。**

| | 直後 | 300ms 後 |
|---|---|---|
| 手札の札に `.card--defense` を足す | `matrix(1, 0, 0, 1, 0, 0)` | **`matrix(0, 0.7, -0.7, 0, 0, 0)`** |

**`transition` の開始値を読んでいただけだった。** 回転は正しく当たっている。
**10-20 の手法には「`transition` を持つ要素では、付けた直後の計算値は前の値である」
という穴がある。** 次の B の夜からは、付けたあと `transition` の時間ぶん待ってから読む。

### 4-3. 実装 — 表示形式が変わる瞬間に、札が回る

`animation` なら新しい要素でも再生されるので、そちらで出す。
**ただし状態から直に決まる `.card--defense` に付けると、守備でいるあいだじゅう再生される。**
`view.ts` が**前回の `position` を `instanceId` ごとに持ち回り**、変わった描き直しだけ
一度きりのクラスを足す（姫神演義が `prevXxx` で揃えているのと同じ形）。
盤から消えた姫神は控えから落とす（同じ `instanceId` が使い回されたときの誤爆を防ぐ）。

| クラス | 動き | 終わったあとに残る値 |
|---|---|---|
| `card--flip-to-defense` | `rotate(0) scale(1)` → `rotate(90deg) scale(0.7)` | `.card--defense` の値 |
| `card--flip-to-attack` | `rotate(90deg) scale(0.7)` → 無し | 無し |

**どちらも 0.22 秒。既存の規則は1行も書き換えていない。**

#### 実測（実機・390×844・dsf2）

| | 通常 | reduce |
|---|---|---|
| `card--flip-to-defense` | `cardFlipToDefense` 0.22s | **`none`** |
| `card--flip-to-attack` | `cardFlipToAttack` 0.22s | **`none`** |
| `card--defense` 単独 | `none` | `none` |

`.card--defense` 単独が通常でも `none` であることが大事で、
**守備でいるあいだ毎回再生されない**ことを示している。

**動いている現物を山（110ms）で止めて撮った。**
`transform` は `matrix(0.377716, 0.699093, -0.699093, 0.377716, 0, 0)` で**回転の途中**。
写真は `shots-2026-10-22/fx-duel-flip.png`。

#### reduce で代わりを置いていない理由

この動きが伝えているのは「向きが変わった」ことで、**向きそのものは
`.card--defense` の静止した回転で見えたまま**だからである。
姫神演義が踏み込み・入れ替えについて「位置そのものが動くので、動かさなくても
結果は見える」と決めたのと同じ理由（maniwa-tcg SPEC 9.4.20）。

**SPEC 9.4.1〜9.4.4 を先に書いてから実装した**（追記のみ・削除0行）。
