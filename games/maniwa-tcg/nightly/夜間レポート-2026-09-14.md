### 7-2. 【新規・実測あり】ポイントの丸が毎回の描き直しで光っていた

`.points__pip--on` には `pipOn` という拡大アニメーションが付いている。しかし
このクラスは状態から直に決まり（`i < player.points`）、描き直しは
`root.replaceChildren()` で**要素を毎回作り直す**。
つまり **点が増えていない描き直しでも毎回再生されていた。**

毒（9.4.7）とまったく同じ誤りである。「いつも光っている」演出は
「いま起きた」ことを伝えられない。

#### 実測（やみ 対 やみ、1試合）

| | 描画 | `pipOn` の再生 | 実際に入った点 |
|---|---|---|---|
| 直す前 | 187回 | **184回** | 2 |
| 直したあと | 181回 | **3回** | 3 |

**直したあとは、入った点の数と再生回数が一致している。**

#### 直しかた

SPEC 9.4.8 を先に追記してから実装した。毒（9.4.7）と同じ差分方式である。

- `prevPoints` を持ち回り、`Fx` に `pointsBefore` を載せる
- **点灯（`--on`）は状態から、光り方（`--gain`）は差分から**決める
- CSS はアニメーションを `.points__pip--on` から `.points__pip--gain` に移しただけ

`prefers-reduced-motion` の一覧も `--gain` に差し替えた。
**点灯そのものは差分と無関係なので、動かさない設定でも点は正しく見える。**

### 7-3. 【09-12 からの積み残し】カード名のバッジ逃げを1行目だけにした

09-12 の 8-1 で「1晩で戻せる規模ではない」として提案に留めていたもの。

`padding-right: 19px` は**全行から一律に削る**が、属性バッジは1行目の高さにしか無い。
ベンチの名前は実効49pxしかなく、19px削ると30px＝12pxの文字で1行あたり2文字強になる。

| 名前 | 場所 | 必要な高さ | 使える高さ |
|---|---|---|---|
| ツァトゥグアEX | ベンチ | 60px | 45px |
| カグツチ / タオテツ / 護符の紐 | 手札 | 59px | 30px |
| 星辰の羅針 / カグツチEX | 手札 | 74px | 30px |

SPEC 9.1.2 を先に追記してから実装した。

```css
.card__name::before {
  content: '';
  float: right;
  width: 19px;
  height: 1.25em;
}
```

1行ぶんの高さを持つ右寄せの空き箱を先頭に置くと、**1行目だけが短くなる。**

**`-webkit-line-clamp` は外した。** `display: -webkit-box` はブロック整形文脈を作るので
浮動要素をよけて横幅そのものが縮む（2026-09-08 に float のバッジで踏んだのと同じ現象）。
打ち切りは `max-height` + `overflow: hidden` に移した。
**この結果、末尾の「…」は出なくなる。**

#### 先に単体で測ってから入れた

`.card__name` だけを取り出した検証用ページで、方式を並べて測った。

| 名前 | 現状（`padding-right`） | 案（1行目だけ逃げる） |
|---|---|---|
| ツァトゥグアEX | 必要65px / 使える51px → **切れる** | 45px / 45px → 収まる |
| プリティヴィー | 必要68px / 使える51px → **切れる** | 45px / 45px → 収まる |
| オオゲツヒメ | 51px / 51px → 収まる | 30px / 30px → 収まる |

#### 9画面で確かめた（切れ 9件 → 0件）

`…` が出なくなる心配は、**切り詰めそのものが起きなければ問題にならない。**
実際に 9画面すべてで切れが0件になった。

| 画面 | 横スクロール | 44px違反 | 低コントラスト | 名前切れ |
|---|---|---|---|---|
| 1-title 〜 8-battle | なし | 0 | 0 | 0 |
| 8b-finish | なし | 0 | 0 | **9 → 0** |
| 9-result | なし | 0 | 0 | 0 |

**合計: 横スクロール 0画面 / 44px違反 0件 / 低コントラスト 0件 / 切れ 0件。**
