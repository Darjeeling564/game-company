### 7-3. ★ 直した: 動きを減らす設定が、8件で効いていなかった（SPEC 9.4.20）

**`@media (prefers-reduced-motion: reduce)` のブロックに `animation: none` と
書いてあるのに、実機では動きが止まっていなかった。**

原因は**詳細度**である。メディアクエリは詳細度を上げない。

```css
.side--human .card--lunge { animation: lungeUp 0.42s ...; }   /* 0-2-0 */

@media (prefers-reduced-motion: reduce) {
  .card--lunge { animation: none; }                            /* 0-1-0 → 負ける */
}
```

#### 実測（390×844 / 実機の盤に一時的にクラスを足し、同じ `evaluate` の中で計算後の値を読んで必ず戻す）

| クラス | reduce なし | **reduce あり（直す前）** | **直した後** |
|---|---|---|---|
| `card--lunge` | lungeUp / lungeDown | **lungeUp / lungeDown** | none |
| `card--swap-in` | swapInUp / swapInDown | **swapInUp / swapInDown** | none |
| `card--swap-out` | swapOutDown / swapOutUp | **swapOutDown / swapOutUp** | none |
| `card--hit` + `card--lunge` | cardHit, lungeUp | **cardHit, lungeUp** | none |
| `card--drained` + `card--swap-in` | cardDrain, swapInUp | **cardDrain, swapInUp** | none |
| `card--hit` + `card--swap-out` | cardHit, swapOutDown | **cardHit, swapOutDown** | none |
| **`drift__card`（タイトルの12枚）** | driftUp **infinite** | **driftUp infinite** | none（反復1） |
| `card--hit` 単体 | cardHit | none | none |
| `card--enter` / `card--draw` | cardPlace / cardDraw | none | none |

**効いているものと効いていないものが混ざっていたので、気付きにくかった。**
`card--hit` 単体は打ち消しも宣言も `.card--hit`（0-1-0）で同じ詳細度、
`card--enter` / `card--draw` は 9.4.18 で `:not(.card--attachable)` を付けたときに
**偶然 0-2-0 になっていた**ので効いていた。

**`drift__card` は唯一の `infinite` の演出で、タイトル画面で回りつづけていた。**

#### 直し方

**上の reduce ブロックは1行も消していない。** 詳細度で勝つ規則を**足しただけ**である
（`style.css` は +49 / −0）。

**「動かさない代わりに何も出さない」にはなっていない。** 踏み込み（lunge）と
入れ替え（swap）が伝えるのは「**自分が何をしたか**」であって「自分に何が起きたか」ではない。
2026-09-26 に `lunge + faint` で**残すのはきぜつのほう**と決めたのと同じ理由である。
入れ替えは札の位置そのものが動くので、動かさなくても結果は見える。

**reduce なしの側は11通りとも直す前と同じ値で、演出は1つも壊れていない**（上の表の左列）。

#### 文字列検査では見つけられない

`style.css` を文字列として調べると **20件**が「reduce に出てこない」と出たが、
**実機で本当に効いていなかったのは8件**だった。差は `:not()` や別ブロックでの手当てである。
**`animation: none` が書いてあることを確かめるだけでは足りない。**
reduce を有効にした実機で**計算後の `animationName` を読む**のが正しい（SPEC 9.4.20 に書いた）。

### 10.4 10-12 の「`tools/` は関門に引っかかる」は誤りだった（訂正）
