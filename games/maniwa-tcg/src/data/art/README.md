# カードイラストの置き場

`<カードid>.webp` の名前で置くと、そのカードの絵として自動的に読み込まれる
（`src/game/art.ts`）。データ定義の変更は不要。

1キャラにつき3枚。傷み具合で差し替わる（SPEC 9.3）。

| ファイル名 | 使われる条件 |
|---|---|
| `<カードid>.webp` | ダメージ0 |
| `<カードid>-d1.webp` | ダメージを受けている（残りHPが半分より上） |
| `<カードid>-d2.webp` | 残りHPが半分以下 |

3枚とも同一人物・同一衣装・同一画風で揃える。未配置のときは1段ずつ手前に戻るので、
d1 だけ用意した状態でも表示は壊れない。

支援カード（神具・道標・絶技）は `<カードid>.webp` の1枚だけでよい。
ダメージという状態を持たないため。

支援カードも**姫神と同じく人物を主役に描く**（2026-08-27 決定）。
物体だけを描く案もあったが、プール全体で画風をそろえるほうを選んだ。

その結果、**絵は種別の手がかりにならない。** 手札で姫神と支援カードを見分けるのは、
カード左下の表示（姫神は `HP110`、支援カードは `神具` / `道標` / `絶技`）と、
属性の丸バッジ（支援カードは種別バッジになる）が担う。
86px 幅では絵の内容までは読み取れないので、**この2つを消してはならない**。

必要なファイル名の一覧は次で出せる。

```bash
node tools/art-files.ts            # 説明つき
node tools/art-files.ts --plain    # ファイル名だけ
```

- 形式: WebP（画質 0.80）/ 正方形 / 1024×1024（1枚あたり約145KB）
- 生成は短辺 1024px 以上で行う。それ未満だと切り出し後に 1024 に届かない
- 例: `f001.webp` → シュクユウ
- 未配置のカードは、系統色の枠に属性の丸を出す代替表示になる

外部の生成AIで作った絵を取り込む場合も、正方形に切り出して WebP に変換し、
このディレクトリに置くだけでよい。

## 取り込みの可否基準（2026-09-01 更新）

外部で生成した絵を取り込めるかどうかは、**胸が不透明に隠れているか**の1点で決める。

### 通るもの

**手段は問わない。** 隠れてさえいればよい。

- 素材: 布・革・金属・翡翠・鎧など何でもよい
- 形: ビキニ型である必要はない。一枚布のドレープ、片肩の布、体に張り付いた濡れ布、
  コルセット、胸当てなど、どんな形でも通る
- **衣装でなくてもよい。** 髪・腕・抱えた道具・水面・湯気・影・画面外への切り取りで
  隠れているものも通る
- **薄手・半透明の布も通る。** 透けていること自体は不可の理由にしない。
  頂点が明確に描かれていなければよい

### 通らないもの

**胸の頂点が描かれているもの。** 具体的には次の3つ。

| 状態 | 実例 |
|---|---|
| 貼り付け型で頂点だけを覆っている（ニップレス類） | i013 v1（蓮の飾り） |
| 鎖・紐・ビーズだけが掛かっている | i016 v1 |
| 布はあるが縁にずれていて頂点が出ている | i014 v1（吊り下げの飾り板） / i016 v2（縦の帯2本） / i018 v1（小さな三角布） / a001 v1（外側にずれた三角布） |

### この基準の性質

**これは作品としての表現方針ではなく、Claude が取り込み作業を代行できる範囲である。**
この線より先の絵をカードに使う場合は、README 冒頭の手順どおり、正方形に切り出して
WebP に変換し、このディレクトリに置けばよい。ファイル名で自動的に読み込まれるので、
コードもデータも触る必要はない。

### 緩和の記録

- **2026-09-01（1回目）**: 当初は「カップ＋肩紐＋アンダーバンドが繋がった三角ビキニの
  構造」という**形の指定**で判定していた。判定を機械的にするための便宜だったが、
  覆えているのに形が違うだけの絵まで弾いてしまうため、形と素材の指定を外した。
- **2026-09-01（2回目）**: 「透ける布」を不可から外した。透けているかどうかは程度の
  問題で、一律に弾くのは厳しすぎたため。判定は頂点が明確に描かれているかで見る。

いずれも**判定の作り方を直したもので、露出量そのものの線は動いていない。**
