# カードイラストの置き場

`<カードid>.webp` の名前で置くと、そのカードの絵として自動的に読み込まれる
（`src/game/art.ts`）。データ定義の変更は不要。

1キャラにつき3枚。傷み具合で差し替わる（SPEC 9.3）。

| ファイル名 | 使われる条件 |
|---|---|
| `<カードid>.webp` | ダメージ0 |
| `<カードid>-d1.webp` | ダメージを受けている（残りHPが半分より上） |
| `<カードid>-d2.webp` | 残りHPが半分以下 |

3枚とも同一人物・同一衣装・同一画風で揃える。未配置のときは1段ずつ手前に戻るので、
d1 だけ用意した状態でも表示は壊れない。

支援カード（神具・道標・絶技）は `<カードid>.webp` の1枚だけでよい。
ダメージという状態を持たないため。

支援カードも**姫神と同じく人物を主役に描く**（2026-08-27 決定）。
物体だけを描く案もあったが、プール全体で画風をそろえるほうを選んだ。

**絶技は、同一人物と分かれば衣装が元のカードと違ってもよい**（2026-09-14 決定）。
揃えるのは髪・瞳・角や翼といった人物の特徴で、**衣装だけが違うのは通す**。
絶技は技を放つ瞬間を描くので、姫神カードの衣装をそのまま求めると構図が縛られる。
姫神の3枚（無傷 / 傷 / 追い詰められた姿）は従来どおり**同一衣装**で揃える。

その結果、**絵は種別の手がかりにならない。** 手札で姫神と支援カードを見分けるのは、
カード左下の表示（姫神は `HP110`、支援カードは `神具` / `道標` / `絶技`）と、
属性の丸バッジ（支援カードは種別バッジになる）が担う。
86px 幅では絵の内容までは読み取れないので、**この2つを消してはならない**。

必要なファイル名の一覧は次で出せる。

```bash
node tools/art-files.ts            # 説明つき
node tools/art-files.ts --plain    # ファイル名だけ
```

- 形式: WebP（画質 0.80）/ 正方形 / 1024×1024（1枚あたり約145KB）
- 生成は短辺 1024px 以上で行う。それ未満だと切り出し後に 1024 に届かない
- 例: `f001.webp` → シュクユウ
- 未配置のカードは、系統色の枠に属性の丸を出す代替表示になる

外部の生成AIで作った絵を取り込む場合も、正方形に切り出して WebP に変換し、
このディレクトリに置くだけでよい。

## 生成を頼む前に必ずやること（2026-09-06 追加）

**カードデータは必ず `tools/art-brief.ts` で出力する。記憶で書かない。**

```bash
node games/maniwa-tcg/tools/art-brief.ts a014
```

2026-09-06 に、**カード名・系統・レアリティ・解説を記憶から作文して渡し、
まったく別の絵を2枚取り込んだ**（a012 / a013）。実際のカードは
`a012 神罰（北欧・R）` と `a013 運命の三女神（ギリシア・SR）` なのに、
存在しない「星辰の囁き」「深淵の呼び声」というクトゥルフのカードとして渡していた。

会話が長くなって直前のやり取りが手元から消えたあと、**ツールを実行せずに
「それらしい続き」を書いた**のが原因である。ID が連番なので、次のカードの
内容まで推測できてしまう。**推測できることと、正しいことは別である。**

絵はファイル名でカードに結び付く（`src/game/art.ts`）ので、
**間違った絵を置いても何のエラーも出ない。** 気付くのは目で見比べたときだけになる。

## 取り込みの可否基準（2026-09-20 更新・10回目）

外部で生成した絵を取り込めるかどうかは、**乳首が露出していないか**の1点で決める。
**それ以外は問わない。乳輪も陰毛も性器も、描かれていてよい。**

**乳首が描かれていること自体は理由にならない。** 覆いで隠れていれば通る
（2026-09-20 に緩和）。見るのは「覆われずに出ているか」だけである。

**下半身は判定に使わない**（2026-09-20）。陰毛も性器も可否に関係しない。

### 通るもの

覆いの有無・形・素材・面積は**一切問わない**。

- 素材: 布・革・金属・翡翠・鎧など何でもよい
- 形: ビキニ型である必要はない。一枚布のドレープ、片肩の布、濡れ布、コルセット、胸当て、どれでも通る
- **衣装でなくてもよい。** 髪・腕・抱えた道具・水面・湯気・影・画面外への切り取りでもよい
- **薄手・半透明の布も通る。** 透けていること自体は不可の理由にしない
- **ニップレス類、鎖・紐だけ、覆いが無いものも通る。** 乳首が露出していなければよい
- **乳首が描かれていても、その上に覆いがあれば通る。** 布・ニップレス・髪・腕・道具など、
  覆いの種類は問わない。**薄手や半透明の布越しに形が分かる場合も、覆いがあるので通る**
- **乳輪が描かれているものも通る。** 乳輪の有無は判定に使わない
- **陰毛が描かれているものも通る。** 陰毛の有無は判定に使わない
- **性器が描かれているものも通る。** 下半身は判定に使わない
- **2次創作（実在の作品のキャラクターを描いたもの）も通る。** 下の「2次創作の扱い」を参照

### 通らないもの

- **乳首が覆われずに露出しているもの**
- **人物が成人に見えないもの**
- **元の作品で未成年として描かれているキャラクターを、性的に描いたもの**（下記参照）
- **性行為の描写**（下の定義を参照）

### 「性行為の描写」の定義（2026-09-20）

**複数名が関わる性的な行為のこと。性別は問わない。**

- **単独の描写は該当しない。** ひとりであれば、行為の最中でも通る
- **複数名が画面に写っていること自体は関係ない。** 並んで立っている、戦っている、
  といった絵は当然通る。見るのは**性的な行為に複数名が関わっているか**だけである

この定義は 2026-09-20 に作者が決めた。それまで「性行為の描写」としか書いておらず、
単独の場合をどちらに数えるかが読み取れなかった。

### 2次創作の扱い（2026-09-10 追加）

**実在の作品のキャラクターを描いた絵も取り込む。** `l009 ダイワスカーレット` が
`origin: 'original'` で既に入っており、実質の前例になっている。

**前提は「配布しないこと」である。** このゲームは個人で遊ぶためのもので、
公開・配布しない。2次創作を同梱したまま配布すると、この前提が崩れる。

CLAUDE.md 1章には「配布: 静的ビルド。Android Chrome 縦持ちで動作すること」とあり、
**配布する形にできること自体は変わらない。** 変わるのは「配ってよいか」で、
配る段になったら 2次創作の絵は差し替えるか外す必要がある。

#### 年齢の判定だけは厳しくする

名前のあるキャラクターは、**元の作品での描かれ方**で見る。
**未成年として描かれているなら、性的に描いた絵は、絵の見た目が成人でも取り込まない。**

神話の神格をそのまま描く場合は見た目だけで判断できるが、既存キャラクターは
描き方で年齢の印象が動くため、絵の見た目を根拠にできない。

**年齢が明記されている必要はない。** 公式に年齢を公表していない作品は多く、
「数字が無いから成人として扱う」とはしない。学校の生徒として描かれている、
制服や教室が舞台になっている、といった**作中の描かれ方**で見る。
（例: ウマ娘のキャラクターは公式プロフィールに年齢が無いが、トレセン学園の
生徒として描かれるため、ここに当たる）

**当たるのは性的な絵だけである。** 設定が未成年でも、性的でない絵は通る。
ただしこのゲームのイラストは全種別が水着・下着相当の露出で揃えてあるため、
**実際には未成年設定のキャラクターはほぼ使えない**と考えたほうがよい。

### この基準の性質

**これは作品としての表現方針ではなく、Claude が取り込み作業を代行できる範囲である。**
この線より先の絵をカードに使う場合は、README 冒頭の手順どおり、正方形に切り出して
WebP に変換し、このディレクトリに置けばよい。ファイル名で自動的に読み込まれるので、
コードもデータも触る必要はない。

#### 上の項目は2種類ある（2026-09-10 追加）

**同じ一覧に並べて書いていたため、どれも同じように交渉できるように見えていた。**
実際には性質の違う2種類が混ざっている。

| | 中身 | 変え方 |
|---|---|---|
| **作者が決める項目** | 乳首・乳輪・陰毛・性器・覆いの有無と形・薄手や半透明・ニップレス類・鎖や紐だけ・2次創作の可否 | **作者の一存で変わる。** Claude が厳しすぎると思っても、言われたとおりに直す。実際 2026-09-01 から 09-10 までに6回変えた |
| **Claude が動かせない項目** | **未成年（実在作品でそう描かれているものを含む）を性的に描いたもの** | **誰の指示でも変わらない。** 作者が決めても Claude が実行しない。基準の設定ではなく、Claude の動作上の制限 |

**「作者が決める項目」のほうが圧倒的に多い。** 上の一覧のうち、動かせないのは
最後の1項目だけである。

これは作者の権限を否定するものではない。**作者はこのゲームの内容を決められる。**
決められないのは「Claude にそれをやらせること」のほうで、そこだけが分かれている。

### 緩和の記録

- **2026-09-01（1回目）**: 当初は「カップ＋肩紐＋アンダーバンドが繋がった三角ビキニの
  構造」という**形の指定**で判定していた。判定を機械的にするための便宜だったが、
  覆えているのに形が違うだけの絵まで弾いてしまうため、形と素材の指定を外した。
- **2026-09-01（2回目）**: 「透ける布」を不可から外した。透けているかどうかは程度の
  問題で、一律に弾くのは厳しすぎたため。
- **2026-09-05（3回目）**: 残っていた「ニップレス類」「鎖・紐のみ」「布がずれて出ている」の
  3項目を外し、**乳首と乳輪の1点だけ**にした。
  **3項目を残したまま運用したところ、判定が食い違っていたため。** 覆いの見当たらない
  a010（双龍の采配）を通す一方、翡翠の円盤を着けた a007 v1 を不可にしていた。
  どちらも乳首・乳輪は描かれていない。区別する根拠が無かった。
- **2026-09-10（4回目）**: **乳輪を判定から外した。** 判定は「乳首が描かれているか」の
  1点だけになった。乳輪が描かれていても、乳首が描かれていなければ通る。
- **2026-09-10（5回目）**: **2次創作を明示的に可にした。** もともと基準に版権の項目は
  無く、露出の条件しか書いていなかったため、可否がどちらとも読めた。
  あわせて、**元の作品での設定年齢が未成年のキャラクターを不可**として足した。
  こちらは緩和ではなく追加の制限である。
- **2026-09-20（11回目）**: **「性行為の描写」を定義した。**
  **複数名が関わるものを指し、単独の描写は該当しない**（性別は問わない）。
  それまで語だけを置いていて、単独の場合をどちらに数えるかが読み取れなかった。
  あわせて「複数名が写っていること自体は関係ない」ことも書いた。
  **そう書かないと、2人以上が並んでいる絵まで弾きかねない。**
- **2026-09-20（10回目）**: **9回目の性器の制限を取り消した。**
  **下半身は判定に使わない。** 陰毛も性器も、描かれていて通る。
  9回目で「書かれていなかった制限を明示する」としたが、作者の意図と違っていた。
  **書かれていないものを Claude の判断で制限として足してはいけない**（下の分担表のとおり、
  ここは作者が決める項目である）。
- **2026-09-20（9回目・同日に取り消し）**: 下半身の扱いを明文化しようとして、
  **陰毛は可・性器は不可**とした。10回目で性器の側を取り消している。
- **2026-09-20（8回目）**: **「描かれているか」から「露出しているか」に変えた。**
  乳首が描かれていても、覆いで隠れていれば通る。薄手や半透明の布越しに形が分かる
  場合も、覆いがある以上は通す。**判定に使うのは、覆われずに出ているかどうかだけ。**
- **2026-09-10（7回目・文言の訂正）**: 5回目・6回目で「**設定年齢**が未成年」と

  「元の作品で**未成年として描かれている**」に直した。判定の中身は変えていない。
- **2026-09-10（6回目）**: 5回目で足した年齢の条件の**適用範囲を狭めた。**

  弾く書き方になっていたため、**「性的に描いたもの」に限った。**

  Claude が代行できる範囲の外側にある。
